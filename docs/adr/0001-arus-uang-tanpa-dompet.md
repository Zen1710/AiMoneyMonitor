# Transaksi dicatat sebagai arus uang, tanpa dompet

Transaksi tidak terikat ke rekening atau dompet mana pun, dan web menampilkan Arus Bulanan, bukan saldo. Tujuannya supaya mencatat lewat chat tetap cepat: Pengguna tidak perlu menyebut sumber uang dan Asisten tidak perlu bertanya balik.

## Consequences

Angka di web tidak akan selalu sama dengan saldo rekening. Kalau dompet ditambahkan nanti, Transaksi lama tidak punya data sumber uang, jadi perlu aturan khusus untuk data tersebut.
